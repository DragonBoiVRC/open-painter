`multi.fbx` was generated with Blender (headless, default FBX export settings) from a scene made
for this project: a cube scaled 2x1x0.5 at (1,2,3) with materials Body/Trim/Glass assigned to
alternate faces, and a UV sphere (radius 0.5, 960 triangles) at (-3,0,1) rotated 90 degrees about Z
using material Trim. It contains no third-party content.
